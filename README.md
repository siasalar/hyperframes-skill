# hyperframes-skill

مجموعه اسکیل برای **Claude Code** و **Codex** که ادیت ویدیو را با
[HyperFrames](https://github.com/heygen-com/hyperframes) و GSAP انجام میدهد.

یک ویدیوی خام بدهید که در آن جلوی دوربین صحبت میکنید. سکوت ها حذف میشوند،
تپق ها و اشتباه ها برای تایید به شما پیشنهاد میشوند، روایت تصویری ویدیو طراحی
میشود و موشن گرافیک ها روی سیستم خودتان رندر میشوند.

## راهنمای سریع برای دانشجوها

**چه چیزی لازم دارید:** برنامه **Claude Code** (اپ دسکتاپ Claude در بخش Code، یا نسخه
ترمینال، یا افزونه VS Code) با اشتراک Claude. چت معمولی سایت claude.ai کار نمیکند،
چون این اسکیل باید روی کامپیوتر خودتان فایل بسازد و ویدیو رندر کند.

**قدم ۱: دانلود و نصب.** در Claude Code بنویسید:

> این ریپو را داخل پوشه Documents دانلود و نصب کن. اگر Node.js یا ffmpeg یا Chrome نصب نیست،
> قبل از نصب به من بگو: https://github.com/siasalar/hyperframes-skill

Claude خودش پوشه `hyperframes-skill` را داخل Documents میسازد. شما لازم نیست پوشه ای بسازید.

**کلید API لازم نیست.** اگر Higgsfield یا ElevenLabs را در Claude به عنوان کانکتور وصل کرده اید
(Settings و بعد Connectors)، Claude خودش آنها را پیدا میکند و میگوید چه چیزی وصل است و چه چیزی
نه. فایل `.env` را فقط کسی لازم دارد که بخواهد به جای کانکتور از کلید API استفاده کند.

**قدم ۲: باز کردن پوشه (مهم).** یک جلسه **جدید** در Claude Code باز کنید و موقع انتخاب
پوشه، پوشه `Documents/hyperframes-skill` را انتخاب کنید. در ترمینال: `cd ~/Documents/hyperframes-skill`
و بعد `claude`. اسکیل ها فقط وقتی فعال میشوند که جلسه داخل همین پوشه شروع شده باشد.

**قدم ۳: پرامپت.** فایل ویدیوها را داخل پنجره Claude بکشید تا مسیرشان نوشته شود.
لازم نیست فرمت را بگویید؛ پیش فرض ریلز اینستاگرام ۹:۱۶ و ۱۰۸۰ در ۱۹۲۰ است.

یک ویدیو:

> ویدیوی اصلی من: [مسیر]. ویدیوی نمونه: [مسیر]. این را به یک ریلز تبدیل کن. زبان ویدیو
> فارسی است. چیدمان، کادربندی، ریتم و حس کلی را از ویدیوی نمونه دربیاور ولی کپی نکن.

دو ویدیو (ویدیوی دوم قبل از هوک ویدیوی اول میاید):

> ویدیوی اصلی اول: [مسیر]. ویدیوی اصلی دوم: [مسیر]. ویدیوی نمونه: [مسیر].
> ویدیوی دوم را قبل از هوک ویدیوی اول بگذار و یک ریلز بساز. زبان ویدیو فارسی است.
> چیدمان و حس کلی را از ویدیوی نمونه دربیاور ولی کپی نکن.

اگر ویدیوی نمونه ندارید، خط نمونه را حذف کنید؛ اسکیل با سبک پیش فرض خودش کار میکند.
اگر چیزی را متفاوت میخواهید (مثلا پس زمینه روشن یا رنگ خاص)، فقط همان را اضافه کنید.

**در طول کار از شما میپرسد:** کدام اکانت برای ساخت تصویر و ویدیو استفاده شود
(اول Higgsfield اگر وصل باشد)، تایید محل چسباندن دو ویدیو، تایید دو فریم نمونه سبک،
و تایید استوری بورد. بعد از تایید ها خودش تا خروجی نهایی پیش میرود.

## امکانات

- **۱۵ اسکیل** برای هر دو دستیار: Claude Code در پوشه `.claude/skills/` و Codex در پوشه `.agents/skills/`
- **۴۰۶ کارت موشن گرافیک آماده** در دو سبک Vox و Kallaway، با متن و رنگ قابل تغییر
- **دو قالب صحنه:** کاغذ شطرنجی تیره و کارت شیشه ای کناری
- **ابزارهای ادیت:** تبدیل گفتار به متن، حذف سکوت، پیدا کردن اشتباه ها، برش، هماهنگی با بیت و بررسی نهایی پروژه
- **ویدیوی کوتاه:** ریلز و یوتیوب شورتس با شروع جذاب، زیرنویس دقیق، افکت صوتی و موسیقی
- **ویدیوی معرفی برند:** ویدیوی ۱۰ تا ۳۰ ثانیه ای که کات هایش روی ضرب موسیقی است
- **پروژه نمونه آماده** که بدون فیلم و بدون کلید API اجرا میشود

## سرویس ها و کلیدهای API

سرویس هایی که با این اسکیل کار میکنند: **Higgsfield** (ساخت عکس، ویدیو و موسیقی)، **ElevenLabs**
(تبدیل گفتار به متن، صدا و افکت صوتی)، **Kie.ai** (ساخت عکس و ویدیو) و **faster-whisper** روی
سیستم خودتان (تبدیل گفتار به متن رایگان). Higgsfield و ElevenLabs با کانکتور و بدون کلید کار
میکنند. جزئیات: [CONNECTED-SERVICES.md](docs/CONNECTED-SERVICES.md)

**اول Higgsfield:** اگر کار به ساخت عکس، ویدیو، موسیقی یا صدا نیاز داشته باشد، دستیار
اول بررسی میکند که اکانت Higgsfield شما وصل است یا نه. اگر وصل باشد میپرسد
«از اکانت Higgsfield شما استفاده کنم، تایید میکنید؟» و تا جواب ندهید چیزی نمیسازد.
اگر تایید نکنید یا اکانت Higgsfield نداشته باشید، سراغ Kie.ai یا اکانت های دیگر شما
میرود، یا بدون ساخت تصویر و فقط با فیلم ها و موشن گرافیک خودتان کار میکند.
جزئیات: [GENERATION-ACCOUNTS.md](docs/GENERATION-ACCOUNTS.md)

به طور پیش فرض، تبدیل گفتار به متن با **ElevenLabs Scribe** و ساخت تصویر و ویدیو
با **Kie.ai** انجام میشود. هر دو اختیاری هستند و حساب و اعتبار خودتان را لازم دارند.
میتوانید به جای آنها از OpenAI Whisper یا faster-whisper روی سیستم خودتان استفاده کنید
(دستیار اول قدرت سیستم را چک میکند و مدل مناسب را انتخاب میکند)،
یا متن آماده ویدیو را با زمان بندی کلمه ها بدهید. پروژه نمونه به هیچ سرویس پولی نیاز ندارد.
راهنمای کامل: [TOOLS-AND-API-KEYS.md](docs/TOOLS-AND-API-KEYS.md)

## ادیت ویدیوی خودتان

پوشه پروژه را در Claude Code یا Codex باز کنید و بنویسید:

> با edit-video ویدیوی من در [مسیر فایل] را ادیت کن. مثال ها و حرف های اصلی را نگه
> دار، سکوت ها را کوتاه کن، برش هایی که برای اشتباه ها پیشنهاد میدهی را قبل از اعمال
> نشانم بده و از سبک کاغذ شطرنجی تیره با چند کارت شیشه ای استفاده کن.

در Claude Code بنویسید `/edit-video` و در Codex بنویسید `$edit-video`.

اگر فقط یک کار مشخص دارید، مستقیم اسکیل همان کار را صدا بزنید، مثلا
`cut-silences` یا `cut-mistakes`. راهنماهای بیشتر:
[مراحل کار](docs/WORKFLOW.md)، [نمونه دستورها](docs/PROMPTS.md) و
[راهنمای روایت](docs/STORYTELLING-WORKBOOK.md)

## ساخت ریلز و یوتیوب شورتس

> با short-form-edit ویدیوی من در [مسیر فایل] را به یک ریلز عمودی تبدیل کن. شروعی
> بساز که کنجکاوی ایجاد کند و آخرش جواب بدهد. حرفم را تغییر نده، اشتباه ها را حذف کن
> و زیرنویس دقیق، تصویر متحرک و افکت صوتی اضافه کن. اول از فیلم های خودم استفاده کن.

در Claude Code بنویسید `/short-form-edit` و در Codex بنویسید `$short-form-edit`.
جزئیات بیشتر: [SHORT-FORM.md](docs/SHORT-FORM.md)

## ساخت ویدیوی معرفی برند (Showreel)

یک ویدیوی کوتاه و پرانرژی برای معرفی برند، که هر کات آن دقیقا روی ضرب موسیقی است
و با لوگوی برند تمام میشود.

> با motion-showreel یک ویدیوی معرفی ۱۵ ثانیه ای برای [نام برند] بساز. یک شکل یا
> نماد اصلی انتخاب کن که در طول ویدیو تغییر شکل بدهد، کات ها را روی ضرب موسیقی بزن
> و ویدیو را با لوگو تمام کن. قبل از ساخت، طرح اولیه صحنه ها را نشانم بده.

در Claude Code بنویسید `/motion-showreel` و در Codex بنویسید `$motion-showreel`.

## ساختار پروژه

| مسیر | توضیح |
| --- | --- |
| `.claude/skills/` | نسخه اصلی اسکیل ها. بعد از هر تغییر دستور `npm run sync:skills` را اجرا کنید |
| `.agents/skills/` | نسخه ساخته شده برای Codex |
| `scripts/` | ابزارهای تبدیل گفتار به متن، برش و بررسی پروژه |
| `style-library/` | کارت های موشن گرافیک و [راهنمای آنها](style-library/GUIDE.md) |
| `style-templates/` | [قالب های کامل صحنه](style-templates/README.md) |
| `video-projects/` | پروژه های ویدیویی. پروژه های جدید شما در گیت ذخیره نمیشوند |
| `docs/` | راهنماها |
| [`MOTION_PHILOSOPHY.md`](MOTION_PHILOSOPHY.md) | اصول حرکت و ترنزیشن |
| [`CLAUDE.md`](CLAUDE.md) و [`AGENTS.md`](AGENTS.md) | دستورالعمل دستیارها |

برای هر ویدیو با دستور `npm run new-video -- my-video` یک پوشه جدا بسازید.
فیلم های خام، متن ها، فایل `.env` و خروجی ها در گیت ذخیره نمیشوند.

## نکته ها

- کارت های موشن گرافیک نسخه اولیه هستند. هر کارت را با متن و فیلم خودتان امتحان کنید.
- بعضی قالب ها GSAP و فونت های گوگل را از اینترنت بارگذاری میکنند. برای خروجی نهایی آنها را داخل پروژه بگذارید.
- بعضی پروژه های نمونه در `video-projects/` لوگو و رنگ های برند AI Automation Society
  را دارند. این ها فقط نمونه هستند و قبل از استفاده باید با برند خودتان عوض شوند.
- اسم ها، آمار و برچسب های داخل کارت ها نمونه هستند. قبل از انتشار ویدیو آنها را با اطلاعات واقعی عوض کنید.
